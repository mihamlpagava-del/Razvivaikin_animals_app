# 🐾 Детская игра «Энциклопедия Животных» (VK Mini App)

Большая интерактивная детская развивающая игра-энциклопедия в мягком пластилиновом 3D стиле (**Claymation**) для платформы **VK Mini Apps**.

---

## 📁 Структура проекта

```text
animal_app/
├── docs/
│   └── image_prompts.md            # Справочник промптов для генерации пластилиновых 3D-картинок
├── public/
│   ├── index.html                  # Полноэкранный интерфейс с поиском и фильтрами
│   └── assets/
│       ├── images/                 # Каталог 3D Claymation PNG и векторных SVG (73 животных)
│       │   ├── pets/               # Домашние питомцы
│       │   ├── farm/               # Ферма
│       │   ├── forest/             # Лес и тайга
│       │   ├── savannah/           # Саванна и джунгли
│       │   ├── ocean/              # Подводный мир
│       │   ├── birds/              # Птицы
│       │   └── dinos/              # Динозавры и древние животные
│       └── audio/
│           ├── sounds/             # Реалистичные звуки животных (.mp3)
│           └── voices/             # Озвучка названий диктором (.mp3)
├── src/
│   ├── app.js                      # Слайдер со свайпами, живой поиск, фильтрация по таксономии
│   ├── style.css                   # Настольный 3D Claymation дизайн, мягкие тени, анимация squash & stretch
│   └── data/
│       ├── animals.js              # База данных из 73 животных с фактами и классификацией (ES Module)
│       └── animals.json            # JSON-версия данных
├── server.cjs                      # Локальный HTTP-сервер с поддержкой MIME-типов
├── start.bat                       # Запуск игры в один клик под Windows
├── package.json
└── README.md
```

## 🌟 Возможности режима «Максимальная Энциклопедия»

1. **Живой поиск животных**:
   - Быстрый поиск в реальном времени по названию (например, «лев», «собака», «дельфин») или по звукоподражанию («гав», «мяу», «р-р-р»).
   - Кнопка быстрой очистки поля поиска (✕).
   - Экран с понятным сообщением и кнопкой сброса, если ничего не найдено.

2. **Двухуровневая система фильтрации**:
   - **Среда обитания / Миры**:
     - ⭐ Все (73 животных)
     - 🐶 Домашние (12)
     - 🐮 Ферма (11)
     - 🌲 Лес (13)
     - 🦁 Саванна (14)
     - 🌊 Океан (12)
     - 🦜 Птицы (6)
     - 🦖 Динозавры (5)
   - **3D Claymation персонажи (40 готовых животных)**:
  - 🐶 **Домашние (100% готовность - 12 из 12)**: Кошка, Собака, Попугай, Хомяк, Кролик, Морская свинка, Канарейка, Черепаха, Геккон, Золотая рыбка, Аксолотль, Хорёк.
  - 🐮 **Ферма (100% готовность - 11 из 11)**: Корова, Лошадь, Овца, Коза, Свинья, Осёл, Петух, Утка, Гусь, Индюк, Пчела.
  - 🦁 **Саванна и джунгли (100% готовность - 14 из 14)**: Лев, Тигр, Слон, Жираф, Зебра, Обезьяна, Бегемот, Носорог, Гепард, Кенгуру, Коала, Панда, Крокодил, Хамелеон.
  - 🌲 **Лес**: Медведь, Волк, Лиса.

3. **Интерактивная карточка в стиле Claymation**:
   - **Таксономический бейдж**: сверху карточки отображается среда и класс (например, `Саванна • Млекопитающее 🐾`).
   - **Познавательный факт**: внизу карточки расположен яркий блок с интересным фактом из жизни животного («💡 Знаешь ли ты?...»).
   - **Пластилиновые анимации**: пружинящий эффект сжатия и растяжения (`squash & stretch`) и покачивания при воспроизведении звука.

4. **Управление и озвучка**:
   - Свайпы влево/вправо на сенсорных экранах (с зацикливанием по отфильтрованному списку).
   - Кнопки со стрелками и клавиатурное управление (`←`, `→`, `Space`, `Enter`).
   - Автоматическая мгновенная остановка звука при перелистывании карточек.
   - Защита от спам-кликов по карточке.
   - Браузерный речевой синтез (Web Speech API) как автоматический фоллбек для озвучки.

## 🚀 Быстрый запуск

Дважды кликните по файлу **`start.bat`** в папке проекта. Игра сразу откроется в браузере по адресу: **`http://localhost:3000`**.
