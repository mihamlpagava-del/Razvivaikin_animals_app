# 🚀 Пошаговая инструкция: Загрузка детской игры в VK Mini Apps

Данная инструкция описывает процесс тестовой загрузки приложения **«Энциклопедия Животных»** на платформу **VK Mini Apps** через встроенный хостинг ВКонтакте и проверку донатов голосами.

---

## 📦 1. Готовый архив для загрузки

Для загрузки в VK уже собран файл:
👉 **`vk_app.zip`** (в корне проекта `d:\Gameproject\animal_app\vk_app.zip`).

> Если вы внесете новые картинки или звуки, просто дважды кликните по файлу **`build.bat`**, и архив **`vk_app.zip`** автоматически обновится!

---

## 🛠️ 2. Создание приложения ВКонтакте

1. Перейдите на официальный портал разработчиков:  
   🔗 **[dev.vk.com/apps](https://dev.vk.com/apps)** (войдите под своим аккаунтом VK).
2. Нажмите зеленую кнопку **«Создать приложение»**.
3. Заполните начальные поля:
   * **Название**: *Энциклопедия Животных (или любое другое)*
   * **Платформа**: выберите **VK Mini App**.
   * **Категория**: *Образование* или *Детям / Игры*.
4. Нажмите **«Перейти к настройке приложения»** и подтвердите создание через SMS / VK ID.

---

## 🌐 3. Загрузка на бесплатный Хостинг ВКонтакте

У ВКонтакте есть бесплатный быстрый хостинг для Mini Apps:

1. В левом меню вашего приложения выберите раздел **«Хостинг»**.
2. В блоке **«Статический хостинг»** нажмите кнопку **«Загрузить архив»**.
3. Выберите файл **`vk_app.zip`** из папки проекта.
4. После окончания загрузки:
   * Нажмите кнопку **«Опубликовать»** (или переключите статус на *Тестирование / В разработке*).
   * Вы увидите ссылку вида: `https://vk.com/app[ID_ПРИЛОЖЕНИЯ]`.

---

## 💎 4. Настройка донатов и голосов (Кнопка «Спасибо»)

В приложении добавлена кнопка **«⭐ Спасибо»** с выбором подарка (3, 5 или 10 голосов):
* Вызов происходит через официальный метод: `VKWebAppShowOrderBox({ type: 'votes', item: 'treat_3' })`.

### Для включения платежей в кабинете VK:
1. В левом меню приложения перейдите в раздел **«Платежи»**.
2. Переведите переключатель **«Платежи»** в положение **Включены**.
3. В тестовом режиме вы можете бесплатно совершать тестовые платежи голосами, чтобы проверить всплывающее окно и реакцию зверят!

---

## 📱 5. Проверка работы игры на смартфонах

1. Откройте приложение по полученной ссылке `https://vk.com/app[ID]`.
2. Либо перейдите в раздел **«Версии для мобильных устройств»** и отсканируйте **QR-код** камерой смартфона в приложении ВКонтакте.
3. Проверьте:
   * Плавные свайпы карточек влево и вправо.
   * Воспроизведение звуков и анимацию `bounce` при тапе.
   * Работу фильтров и живого поиска.
   * Нажатие на кнопку **«⭐ Спасибо»** и вызов окна списания голосов.
